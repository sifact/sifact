I build AI systems that companies can actually trust in production: assistants that answer only from the right documents, agents that recover from their own mistakes, and ML models served behind clean web apps. Every project ships with an evaluation suite, so the results are measured, not claimed.

- 🤖 **What I build:** RAG over company data, multi-agent systems, voice and multimodal assistants, ML classifiers and recommenders
- 📏 **How I build:** golden-set evals first, guardrails (role-based access, prompt-injection and PII checks), tracing, then a live demo
- 🌐 **Background:** full-stack web development (MERN, Next.js, TypeScript), so every model gets a usable UI and API
